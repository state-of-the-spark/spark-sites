- **Assessment**
  - Review all social media profiles
  - Review current Google Analytics
  - Review current Google Search rankings per the desired key words
- **Plan**
  - Narrow Initial Target Niche
  - Decide on Keywords they Use
  - Google Trends (compare desired key words to performance of other near keywords)
  - Google Keyword Planner
  - Outline Social Media profiles to use
  - Outline post topics for the coming period
- **Implement**
  - Establish SEO onsite
  - Set up verified Google Business Listing
  - Set up Google My Business on cell phone (to push to Google+)
  - Establish a Posting Schedule
  - Establish a Hootsuite/BufferApp account
- **Evaluate**
  - Create content for a planned set of Key Words for 3 months.
  - Schedule Monthly Google Analytics Review
  - Note the top-performing posts and post types
  - Plan, Implement, and Evaluate to narrow the target.
